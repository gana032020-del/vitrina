## Por qué este proyecto

En México y LATAM el cobro real ya ocurre en WhatsApp y SPEI. Gumroad y similares se llevan un recorte. Vitrina es el mostrador; el dinero llega a tu cuenta.

Este es el proyecto con el que se puede cobrar esta semana. SELLO, Cotiza y el POS de laboratorio siguen como productos y servicios dentro del catálogo.

## Cómo cobrar

1. Abre **Estudio → Marca**.
2. Pon tu WhatsApp con lada (ej. `52155…`).
3. Pon tu CLABE / instrucciones SPEI o PayPal.
4. Comparte el enlace de la vitrina.
5. Cuando entre el dinero, marca el pedido como **Pagado** y entrega.

Los cambios del estudio se guardan en ese dispositivo. Exporta un JSON de vez en cuando como respaldo.
